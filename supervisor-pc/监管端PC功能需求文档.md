### 2.2 围挡状态计算规则

围挡状态根据关联的所有项目工程中最晚的工期时间自动计算：
- **设置中**：当前在正常工期内
- **即将拆除**：距离计划拆除日期不足30天
- **超期未拆除**：已超过计划拆除日期
- **已拆除**：已标记拆除完成

## 三、功能清单

### 3.1 围挡档案管理列表页（index_v2.html）

#### 搜索筛选区

- **项目名称**：文本输入，模糊搜索
- **工程名称**：文本输入，模糊搜索
- **地址**：文本输入，模糊搜索
- **围挡状态**：下拉选择（全部/设置中/即将拆除/超期未拆除/已拆除）
- **问题状态**：下拉选择（全部/正常/待整改/整改逾期）
- **围挡长度(m)**：数值输入，最小值筛选
- **占道面积(m²)**：数值输入，最小值筛选
- **计划拆除时间**：日期选择
- **查询按钮**：执行搜索
- **重置按钮**：清空所有筛选条件

#### 状态标签页

- **全部**：显示所有记录，显示数量统计
- **已建档**：仅显示已关联围挡的记录
- **未建档**：仅显示尚未关联围挡的记录

#### 工具栏按钮

- **批量导入**：打开导入弹窗（支持 .xlsx/.xls/.csv，单次最多500条）
- **导出**：导出当前列表数据
- **新增围挡**：跳转到新增围挡表单页（detail_v2.html）

#### 数据表格列

| 列名 | 宽度 | 说明 |
|------|------|------|
| 围挡编号 | 110px | WD-YYYY-NNNN格式 |
| 项目工程 | 22% | 项目名 · 工程名 |
| 地址 | 18% | |
| 行业类型 | 6% | 居中 |
| 围挡状态 | 7% | 居中，带颜色标签 + tooltip说明计算规则 |
| 围挡长度(m) | 8% | 居中 |
| 占道面积(m²) | 8% | 居中 |
| 问题状态 | 7% | 居中，颜色区分正常/待整改/整改逾期 |
| 计划拆除日期 | 9% | 居中 |
| 更新时间 | 9% | 居中 |
| 操作 | 18% | 居中，可换行 |

#### 操作按钮（每行）

**已建档行：**
- **详情**：跳转到围挡详情页 detail_info_v2.html，传递 project + engineering 参数
- **巡检记录**：跳转到围挡详情页巡查记录Tab，URL带 #sec-inspect hash
- **校核**：跳转到围挡校核页 change_v2.html
- **二维码**：弹出二维码弹窗
- **删除**：弹出删除确认弹窗

**未建档行：**
- **新增围挡**：触发新增流程（检查红线 → 选择方式）

#### 共用围挡展示

当一个围挡被多个工程共用时：
- **主行**：显示围挡编号（加粗蓝色）+ 所有工程名（蓝色加粗链接）+ 围挡整体信息
- **子行**：展开显示每个工程的详细信息（项目名·工程名 + 地址 + 行业类型）
- 左侧有蓝色竖条标识分组
- 主行背景色 #EFF5FC，子行背景色 #F6F9FE

#### 分页器

- 显示总记录数
- 翻页按钮（上一页/页码/下一页）

#### 弹窗

1. **批量导入弹窗**：文件上传区域（拖拽或点击），支持格式提示，文件选择反馈
2. **删除确认弹窗**：红色警告图标 + 确认文字 + 围挡详情（共用围挡显示包含的工程列表）
3. **二维码弹窗**：围挡名称 + 二维码图片（SVG模拟）+ 下载按钮 + 点击可模拟扫码
4. **红线未完善提醒弹窗**：警告图标 + 提示文案 + 工程信息 + 「前往完善红线」按钮
5. **新增方式选择弹窗**：两个选项卡片（radio样式）
   - 新增围挡：为此项目工程创建全新围挡记录
   - 关联现有围挡：将此项目工程与已有围挡绑定
6. **关联围挡弹窗**（modal-lg, 720px宽）：
   - 顶部信息栏：当前项目 + 当前工程
   - 搜索框：搜索围挡编号/地址/关联项目
   - 围挡列表：每项显示编号、地址、状态、长度、已关联工程数
   - 地址匹配的项目显示「推荐」标签
   - 单选（radio），确认关联

#### 新增围挡流程

1. 点击「新增围挡」→ 检查该项目是否已绘制红线
2. **红线未完善** → 弹出提醒弹窗 → 可跳转红线绘制页面
3. **红线已完善** → 弹出选择方式弹窗
4. 选择「新增围挡」→ 跳转到 detail_v2.html（带 project/engineering/address 参数）
5. 选择「关联现有围挡」→ 弹出关联围挡弹窗 → 选择围挡 → 确认关联

### 3.2 围挡详情页（detail_info_v2.html）

#### 页面头部

- 面包屑：首页 / 围挡档案管理 / 围挡详情

- 操作按钮：「返回列表」「校核信息」

#### 章节导航（左侧固定）

7个Tab，点击锚点滚动到对应section，滚动时高亮当前section：

1. 所属项目工程
2. 计划信息
3. 围挡本体信息
4. 围挡占道信息
5. 巡查记录
6. 校核记录
7. 变更记录

#### Section 1：所属项目工程

- 按项目分组展示，每组包含：
  - 项目名称 + 工程数量
  - 监管单位
  - 每个工程的卡片（可折叠展开）：
    - 工程计划工期（带时钟图标）
    - 所属区域
    - 地址
    - 建设单位 + 联系人
    - 施工单位 + 联系人
    - 监理单位
    - 设计单位

#### Section 2：计划信息

- 计划拆除日期
- 围挡变更计划（文件下载链接）

#### Section 3：围挡本体信息

- **围挡范围地图**：Leaflet地图，显示围挡多边形（蓝色虚线）+ 项目红线（红色实线）
  - 图例说明
  - 地址覆盖层
  - 已绘制点位数量
  - 出入口标记（如有）
- 围挡长度（m）
- 围挡高度（m）
- 围挡设置时间
- 围挡拆除时间
- 围挡材质
- 所属街道
- 围挡责任人
- 围挡责任人联系电话
- 围挡风格
- 宣传画/公益广告

#### Section 4：围挡占道信息

- 占道面积（㎡）
- 占道范围
- 交通组织方案（文件下载链接）

#### Section 5：巡查记录

**工具栏：**
- 左侧：Segmented Control（最近7天 / 本月 / 自定义）
  - 自定义模式：展开日期区间选择器（滑入动画）
- 右侧：统计文字「本月已巡检 N 次 · 累计 N 张全景照片」+ 新增巡检按钮

**日期分组标题（方案A — 线条分隔式）：**
```
05月07日 星期三 ────────── 3条记录  收起
```
- 可折叠/展开

**巡检卡片网格：**
- 全景缩略图（160px高，background-image）
  - 右上角「全景」角标
  - 左上角红色「问题」角标（仅hasIssue=true时显示）
  - 左下角白色半透明时间水印（如 09:32）
- 信息区：
  - 巡检人：姓名（单位）
  - 巡检位置：位置描述
  - 问题备注：仅 hasIssue=true 且有备注时展示，黄色警示条样式
- 底部操作栏（三个按钮）：
  - 查看全景：写入IndexedDB → 打开 panorama_preview.html
  - 编辑全景：写入IndexedDB → 打开 panorama_editor.html
  - 删除：弹出确认删除弹窗

**弹窗：**
- 新增巡检弹窗：巡检日期、时间、巡检人、单位、位置、全景照片上传、是否发现问题、备注
- 编辑巡检弹窗：同新增，预填数据
- 确认删除弹窗

**IndexedDB数据共享：**
- 数据库名：panorama_project_db
- Store：projects
- Key：active
- 写入全景数据后通过 window.open 打开预览/编辑页面

#### Section 6：校核记录

时间线展示，每条记录包含：
- 蓝色圆点 + 对勾图标
- 校核时间 + 校核人（单位 · 角色）
- 角色标签「校核修正」
- 变更字段列表：字段名 → 旧值 → 新值
- 可选：地图对比（校核前/校核后的围挡范围变化）

#### Section 7：变更记录

时间线展示，每条记录包含：
- 黄色圆点 + 对勾图标
- 变更时间 + 变更人（单位 · 角色）
- 角色标签「变更操作」
- 变更字段列表：字段名 → 旧值 → 新值

### 3.3 新增围挡页（detail_v2.html）

- 面包屑：首页 / 围挡档案管理 / 新增围挡
- 页面标题：「新增围挡」
- 操作按钮：「取消」「存草稿」「保存」

**Section 1：所属项目工程**
- 项目名称：带搜索的下拉选择器
- 工程名称：多选checkbox列表（选中项目后加载）
  - 未完善红线的工程标记警告，不可添加
  - 已选列表展示，可删除

**Section 2：计划信息**
- 计划拆除日期：日期选择
- 围挡变更计划：文件上传（.pdf/.doc/.docx，≤20MB）

**Section 3：围挡本体信息**
- 围挡范围：Leaflet地图绘制工具
  - 绘制范围按钮：点击后在地图上点击添加多边形顶点
  - 编辑点位按钮：拖拽调整已有点位
  - 撤回按钮：撤回最后添加的点位
  - 清空绘制按钮：清除所有绘制
  - 图例（围挡范围/项目红线）
  - 已绘制点位数量
  - 出入口管理：
    - 添加出入口按钮
    - 点击地图放置出入口标记
    - 出入口列表（可命名/删除）
- 围挡长度：数值输入 + m 单位
- 围挡高度：数值输入 + m 单位
- 围挡设置时间：日期选择
- 围挡拆除时间：日期选择
- 围挡材质：文本输入
- 所属街道：下拉选择
- 围挡责任人：文本输入
- 围挡责任人联系电话：电话输入
- 围挡风格：文本输入
- 宣传画/公益广告：文本输入

**Section 4：围挡占道信息**
- 占道范围：文本输入
- 占道面积：数值输入 + ㎡ 单位
- 交通组织方案：文件上传

**JS逻辑：**
- 项目切换 → 加载对应工程的checkbox列表 → 检查红线状态
- 添加工程 → 校验红线是否完善
- 地图初始化 → 根据项目定位到对应区域
- 绘制/编辑/撤回/清空 围挡范围
- 出入口管理（添加/删除/命名）
- 保存表单数据

## 四、业务规则

### 4.1 围挡状态

- 仅允许4种状态：**设置中、即将拆除、超期未拆除、已拆除**
- 状态由系统根据计划拆除日期自动计算，不可手动设置
- 计算规则：基于关联的所有项目工程中最晚的工期结束日期
  - 距离拆除日期 > 30天 → 设置中
  - 距离拆除日期 ≤ 30天 → 即将拆除
  - 已超过拆除日期 → 超期未拆除
  - 已标记拆除 → 已拆除

### 4.2 问题状态

- 三种状态：**正常、待整改、整改逾期**
- 发现问题后变为「待整改」
- 超过整改期限未完成 → 「整改逾期」

### 4.3 红线前置校验

- 新增围挡前，必须先完善该项目工程的红线信息
- 未绘制红线的工程，在新增围挡时显示警告，引导用户前往红线管理完善

### 4.4 共用围挡

- 一个围挡可被多个项目工程共用
- 共用围挡在列表中显示为主行 + 子行的分组形式
- 围挡状态取所有关联工程中最晚的工期计算

### 4.5 校核与变更记录

- 校核操作由监管单位执行，记录每次校核的字段变更（旧值→新值）
- 变更操作由施工单位执行，同样记录变更对比
- 涉及围挡范围/出入口的变更，记录地图对比

### 4.6 全景数据共享

- 使用 IndexedDB（`panorama_project_db`，store `projects`，key `active`）在页面间传递全景数据
- 查看全景/编辑全景时，先将数据写入 IndexedDB，再通过 window.open 打开对应页面

## 五、APP端适配建议

### 5.1 核心功能优先级

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | 围挡列表查看 | 搜索筛选、状态标签切换 |
| P0 | 围挡详情查看 | 7个Tab章节的移动端适配 |
| P0 | 巡检记录 | 新增巡检（手机拍照）、查看全景、问题上报 |
| P1 | 二维码扫描 | 扫码查看围挡信息 |
| P1 | 围挡校核 | 移动端校核表单 |
| P2 | 红线查看 | 移动端地图展示 |
| P2 | 数据统计 | 简化版统计面板 |

### 5.2 移动端特殊交互

- **全景照片**：利用手机陀螺仪实现方向感应浏览
- **地图绘制**：简化为点击地图添加点位，适合触屏操作
- **拍照上传**：直接调用手机相机拍摄全景/巡检照片
- **二维码扫描**：调用手机摄像头扫描围挡二维码
- **定位**：利用GPS自动填充巡检位置

### 5.3 移动端需保留的筛选字段

- 围挡状态（下拉）
- 问题状态（下拉）
- 行政区（下拉）
- 关键字搜索（统一搜索框）

### 5.4 移动端数据展示简化

- 列表卡片化：每张卡片显示围挡编号、项目工程、地址、状态标签
- 详情页使用底部Tab切换（替代左侧章节导航）
- 校核记录/变更记录可折叠展示
- 巡检记录保留卡片式展示，适合竖屏浏览
