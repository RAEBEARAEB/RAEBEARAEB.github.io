# 项目端 PC 功能需求文档

> 本文档描述项目端 PC 系统的功能需求与页面规格，供前端开发人员参考实现。项目端面向施工单位/建设单位，操作权限与菜单范围与监管端有明确区分。

---

## 一、模块总览

项目端 PC 系统包含以下功能模块：

| 序号 | 模块名称 | 入口/页面文件 | 功能说明 |
|------|----------|---------------|----------|
| 1 | 首页工作台 | index.html | 仪表盘：统计卡片、待办/预警列表、趋势图表 |
| 2 | 围挡档案管理 | index_v2_project.html | 当前项目围挡列表，支持列表/地图双视图，提供新增/变更/删除/导入导出 |
| 3 | 围挡详情 | detail_info_v2_project.html | 围挡完整详情，6 个章节左侧锚点导航 |
| 4 | 新增围挡 | detail_v2_project.html | 新建围挡表单，含地图绘制工具 |
| 5 | 围挡变更 | change_v2_project.html | 围挡信息变更修改表单，预填当前数据 |
| 6 | 项目红线管理 | redline.html | 项目红线列表，查看/绘制/删除/变更记录 |
| 7 | 红线绘制 | redline-draw.html | 全屏地图绘制项目红线范围，支持多范围 |
| 8 | 全景预览 | panorama_preview.html | Pannellum 全景照片查看器，支持场景切换 |
| 9 | 全景编辑 | panorama_editor.html | 全景照片场景管理、热点标注与平面图编辑 |

### 全局布局

- **Header**（固定 56px）：系统标题"深圳市建设施工围挡数字化管理系统" + 全屏/消息/通知/帮助按钮 + 用户信息（头像、姓名、角色"项目端负责人"、所属单位）
  - 消息图标含未读计数（badge=3）
  - 通知图标含未读计数（badge=5）
- **Sidebar**（固定 220px）：左侧深色导航栏（背景色 #0D2B55），含导航分组，存在两种变体：
  - **精简版**（index.html / index_v2_project.html / detail_info_v2_project.html / redline.html / redline-draw.html）：首页 / 围挡管理（围挡档案管理、项目红线管理）/ 系统管理（项目管理）
  - **完整版**（detail_v2_project.html / change_v2_project.html）：在精简版基础上增加 围挡巡查管理 / 整改督办 / 数据分析（统计分析、数据导出）/ 系统设置
- **主内容区**：面包屑导航 + 页面标题 + 内容，水平居中，最大宽度约束
- **版本标识**：v2.0.0 · 2026.05

### 全局导航菜单

**精简版菜单（多数页面）：**
- 首页
- 围挡管理
  - 围挡档案管理
  - 项目红线管理
- 系统管理
  - 项目管理（占位，待开发）

**完整版菜单（新增/变更页面）：**
- 监管总览（替代"首页"）
- 围挡管理
  - 围挡档案管理
  - 围挡巡查管理
  - 整改督办
- 数据分析
  - 统计分析
  - 数据导出
- 系统管理
  - 项目管理
  - 系统设置

### 与监管端的主要差异

| 对比项 | 监管端 | 项目端 |
|--------|--------|--------|
| 用户角色 | 监管单位（各区住建局） | 施工单位/建设单位 |
| 菜单范围 | 含巡查管理、整改督办、统计分析、数据导出、系统设置 | 精简版仅围挡管理和红线管理 |
| 列表筛选 | 多字段搜索（项目/工程/地址/状态/面积/日期） | 按项目下拉选择 + 状态标签页 |
| 校核/变更 | 校核（监管单位执行） | 变更（施工单位执行） |
| 红线管理 | 仅查看红线 | 可绘制红线 |
| 操作按钮 | 校核 + 二维码 + 删除 | 变更 + 二维码 + 删除 |

### 2.2 围挡状态计算规则

系统根据关联工程中最晚的计划拆除日期自动计算：

| 状态 | 条件 | 列表标签颜色 |
|------|------|-------------|
| 设置中 | 当前日期 ≤ 计划拆除日期，且距离拆除 > 30 天 | 蓝色 |
| 即将到期 | 距离计划拆除日期 ≤ 30 天 | 黄色 |
| 已超期 | 已超过计划拆除日期 | 红色 |
| 已到期 | 标记拆除完成 | 灰色 |

### 3.2 围挡档案管理列表页（index_v2_project.html）

#### 面包屑

首页 / 围挡管理 / 围挡档案管理

#### 项目选择器

- 下拉选择项目（仅显示当前用户所属项目）
- 选中后展示项目概况信息行：行政区划、项目状态、行业类型、红线状态、围挡计划拆除时间
- "新增围挡记录"按钮（触发新增流程，含红线检查和方式选择）

#### 列表/地图双视图切换

页面标题右侧提供"列表"和"地图"两个切换按钮，控制两种视图的显隐。

**列表视图：**

- **状态标签页**：全部 / 设置中 / 即将到期 / 已超期 / 已到期，每项显示数量统计
- **工具栏**："下载二维码" / "批量导入" / "导出" 三个按钮
- **数据表格**（11 列）：

| 列名 | 宽度 | 说明 |
|------|------|------|
| 序号 | 40px | |
| 围挡管护期限 | auto | 日期区间，如 2025-03-01 ~ 2026-05-31 |
| 围挡状态 | auto | 居中，带颜色标签（蓝/黄/红/灰） |
| 是否待校核 | auto | 居中 |
| 责任单位 | auto | |
| 关联工程 | auto | |
| 工程状态 | auto | 居中，带圆点指示器 |
| 围挡长度(m) | auto | 居中 |
| 占道面积(㎡) | auto | 居中 |
| 问题状态 | auto | 居中，带颜色标签 |
| 操作 | 140px | 详情 / 变更 / 巡检记录 |

- **共用围挡分组**：当同一围挡被多个工程共用时，以主行 + 子行形式展示，左侧蓝色竖条标识
- **排序规则**：已超期 > 即将到期 > 设置中 > 已到期
- **分页器**：显示"共 N 条"，带上一页/下一页/页码按钮

**地图视图：**

- Leaflet 卫星影像地图（Esri World Imagery）
- 缩放按钮、图例（项目红线 / 围挡范围 / 出入口）
- **右侧面板**：围挡记录卡片列表，每张卡片显示序号徽章、管护期限、状态标签、责任单位、关联工程、工程状态
- **联动交互**：卡片 hover 高亮地图对应围挡多边形；地图围挡 hover 高亮对应卡片

#### 操作按钮（每行）

**已建档行：**
- **详情**：跳转围挡详情页 `detail_info_v2_project.html`
- **变更**：跳转围挡变更页 `change_v2_project.html`
- **巡检记录**：跳转详情页巡检区域
- **二维码**：弹出二维码弹窗

**未建档行：**
- 仅显示"新增围挡"操作

#### 新增围挡流程

1. 选择项目 → 点击"新增围挡记录"
2. 校验项目是否已绘制红线
3. 红线未完善 → 弹出提示弹窗 → 可跳转红线绘制页
4. 红线已完善 → 弹出方式选择弹窗
   - "新增围挡"：跳转 `detail_v2_project.html`
   - "关联现有围挡"：弹出搜索关联弹窗（搜索 + 列表单选 + 地址推荐匹配）

#### 弹窗列表（共 7 个）

| 弹窗 ID | 标题 | 内容 |
|---------|------|------|
| importModal | 批量导入围挡数据 | 文件拖拽上传区（支持 .xlsx/.xls/.csv，最多 500 条），上传结果展示 |
| deleteModal | 删除确认 | 红色警告图标 + 围挡详情 + 取消/确认删除按钮 |
| qrcodeModal | 围挡二维码 | 二维码 SVG（模拟跳转 qrcode.html），下载按钮 |
| qrCodeModal | 下载围挡二维码 | 双栏布局：左侧围挡勾选列表（hover 预览），右侧二维码预览图 + 项目/工程标签，全选 + 确认下载 |
| redlineWarningModal | 提示 | 警告图标 + "请先完善工程红线信息" + 前往完善红线按钮 |
| choiceModal | 请选择操作方式 | 两个单选项卡片：新增围挡 / 关联现有围挡 |
| assocModal | 关联现有围挡 | 项目/工程信息条 + 搜索输入框 + 可选围挡列表（推荐标签=地址匹配），取消/确认关联 |

### 3.3 围挡详情页（detail_info_v2_project.html）

#### 页面头部

- 面包屑：首页 / 围挡档案管理 / 围挡详情
- 页面标题："围挡详情" + 蓝色竖条装饰
- 操作按钮："返回列表" / "变更信息"（跳转变更页）/ "删除"（红色危险按钮，弹确认窗）

#### 章节导航

页面采用左侧固定章节导航（scroll-spy 高亮当前章节），共 6 个章节，点击平滑滚动：

**Section 1：关联项目工程**

- 项目名称、工程名称、责任单位、管护期限、围挡责任人、联系电话，均为只读展示
- 可折叠的"工程信息"卡片（5 列网格）：监管单位、建设单位、施工单位、监理单位、设计单位、工程计划工期、所属区域、地址、建设单位联系人、施工单位联系人

**Section 2：项目围挡计划信息**

- 围挡设置时间
- 计划拆除时间
- 围挡变更计划（文件下载链接）

**Section 3：围挡本体信息**

- **围挡范围地图**：Leaflet 卫星影像，展示：
  - 围挡多边形/线段（蓝色）
  - 项目红线叠加层（红色填充 15% 不透明度）
  - 同项目其他围挡参照（灰色虚线多边形 + 出入口圆圈标记，含 tooltip）
  - 出入口标记（按类型着色：车辆=蓝色、行人=绿色、临时=橙色、其他=红色）
  - 地图图例 + 地址覆盖层
- **出入口列表**：只读，每项带颜色圆点类型标识
- 信息字段网格（只读）：所属街道、围挡材质、围挡长度、围挡高度、围挡风格、宣传画/公益广告

**Section 4：围挡占道信息**

- 占道范围
- 占道面积（㎡）
- 交通组织方案（文件链接）

**Section 5：巡查记录**

- **工具栏**：
  - 时间段筛选：最近 7 天 / 本月 / 自定义（日期区间选择器）
  - 右侧：巡检统计数据 + "新增巡检"按钮
- **巡检卡片列表**：按日期分组，每天显示日期标题（含星期 + 记录数）
  - 卡片：全景缩略图（"全景"角标 + 时间水印）、巡检人、巡检位置、所属单位、备注（黄色背景）、问题标签（红色）、操作按钮（查看详情 / 删除）
  - 卡片 hover 上浮阴影效果
- **新增巡检弹窗**：巡检日期、巡检时间、巡检人、所属单位、巡检位置、全景照片上传（含缩略图预览）、备注、问题项复选框
- **删除确认弹窗**：危险图标 + 确认操作
- **Toast 提示**：操作结果反馈

**Section 6：校核与变更记录**

## 四、业务规则

### 4.1 围挡状态

- 4 种状态：**设置中、即将到期、已超期、已到期**
- 由系统根据计划拆除日期自动计算，不可手动设置
- 列表排序：已超期 > 即将到期 > 设置中 > 已到期

### 4.2 问题状态

- 3 种状态：**正常、待整改、整改逾期**

### 4.3 红线前置校验

- 新增围挡前，必须先完善项目红线
- 红线未绘制时弹出提示弹窗，引导前往红线绘制页
- 红线已绘制时弹出方式选择弹窗（新增/关联）

### 4.4 共用围挡

- 一个围挡可被多个工程共用
- 列表中以主行 + 子行分组形式展示，左侧蓝色竖条标识
- 地图视图中标注为共用围挡

### 4.5 变更与校核的区别

- **项目端 → 变更**：施工单位/建设单位发起，修改围挡信息，生成变更记录，"是否待校核"标记为 true
- **监管端 → 校核**：监管单位校核变更内容，可修正字段，生成校核记录（校核通过/校核修正/不通过）
- 两者的表单结构和操作流程基本相同，区别在于角色权限和记录类型

### 4.6 围挡范围坐标校验

- 新增/变更围挡时，围挡范围需落在所属街道行政边界内
- 通过点-in-多边形算法 + 街道边界坐标进行校验

### 4.7 数据权限

- 项目端用户只能查看和操作所属项目的围挡数据
- 列表页项目下拉仅显示当前用户有权限的项目
- 地图视图仅渲染当前项目范围内的围挡

## 五、APP 端适配建议

### 5.1 核心功能优先级

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | 列表查看与项目切换 | 按项目筛选、状态过滤、地图总览 |
| P0 | 围挡详情 | 6 个章节移动端适配，含地图和巡检记录 |
| P0 | 巡检记录 | 新增巡检（手机拍照）、查看全景、问题上报 |
| P0 | 围挡变更 | 移动端变更表单，字段预填可编辑 |
| P1 | 二维码扫描 | 扫码查看围挡信息 |
| P1 | 红线绘制 | 移动端地图绘制 |
| P2 | 全景编辑 | 简化版热点标注 |
| P2 | 数据导出 | 简化版导出 |

### 5.2 移动端适配要点

- **全景浏览**：利用手机陀螺仪实现方向感应
- **地图绘制**：触屏优化，点击添加顶点，双指缩放
- **拍照上传**：调用手机相机拍摄巡检/全景照片
- **二维码扫描**：调用摄像头扫码查询围挡
- **GPS 定位**：自动填充巡检位置

### 5.3 与监管端 APP 的差异

| 对比项 | 监管端 | 项目端 |
|--------|--------|--------|
| 用户角色 | 监管单位 | 施工单位/建设单位 |
| 主要操作 | 校核 | 变更 |
| 红线功能 | 仅查看 | 可绘制 |
| 数据范围 | 所有项目 | 仅所属项目 |
| 统计分析 | 有 | 无 |
