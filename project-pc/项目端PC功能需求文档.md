# 项目端 PC 功能需求文档

> 本文档基于现有 PC 端原型页面提取，供 AI 生成 APP 端原型使用。项目端面向施工单位/建设单位，与监管端相比，操作权限和菜单范围有所不同。

---

## 一、模块总览

项目端 PC 系统包含以下功能模块：

| 序号 | 模块名称 | 页面文件 | 功能说明 |
|------|----------|----------|----------|
| 1 | 首页 | index.html | 项目端首页仪表盘 |
| 2 | 围挡档案管理 | index_v2_project.html | 当前项目下的围挡列表，新增/变更/删除 |
| 3 | 围挡详情 | detail_info_v2_project.html | 围挡完整详情，含7个Tab章节 |
| 4 | 新增围挡 | detail_v2_project.html | 新建围挡表单，含地图绘制 |
| 5 | 围挡变更 | change_v2_project.html | 围挡信息变更修改表单 |
| 6 | 项目红线管理 | redline.html | 项目红线列表 |
| 7 | 红线绘制 | redline-draw.html | 地图绘制项目红线范围 |
| 8 | 全景预览 | panorama_preview.html | Pannellum 全景照片查看器 |
| 9 | 全景编辑 | panorama_editor.html | 全景照片标注编辑器 |

### 全局布局

- **Header**：系统标题「深圳市建设施工围挡数字化管理系统」+ 全屏/消息/通知/帮助按钮 + 用户信息（姓名、角色、所属单位）
- **Sidebar**：左侧深色导航栏（#0D2B55），菜单项比监管端精简
- **主内容区**：面包屑导航 + 页面标题 + 内容

### 全局导航菜单

- 首页
- 围挡管理
  - 围挡档案管理
  - 项目红线管理
- 系统管理
  - 项目管理（待开发）

### 与监管端的主要差异

| 对比项 | 监管端 | 项目端 |
|--------|--------|--------|
| 用户角色 | 监管单位（各区住建局） | 施工单位/建设单位 |
| 菜单范围 | 巡查管理、整改督办、统计分析、数据导出、系统设置 | 仅围挡管理和红线管理 |
| 列表筛选 | 多字段搜索（项目/工程/地址/状态/面积/日期） | 按项目下拉选择 + 状态Tab |
| 校核/变更 | 校核（监管单位执行） | 变更（施工单位执行） |
| 红线管理 | 查看红线 | 绘制红线 |
| 操作按钮 | 校核 + 二维码 + 删除 | 变更 + 二维码 + 删除 |

### 2.2 围挡状态计算规则

同监管端，围挡状态根据关联的所有项目工程中最晚的工期时间自动计算：
- **设置中**：当前在正常工期内
- **即将拆除**：距离计划拆除日期不足30天
- **超期未拆除**：已超过计划拆除日期
- **已拆除**：已标记拆除完成

## 三、功能清单

### 3.1 围挡档案管理列表页（index_v2_project.html）

#### 项目选择器

- **项目名称**：下拉选择（仅显示当前用户所属的项目）
- **新增围挡按钮**：根据选中项目新增围挡

#### 状态标签页

- **全部**：显示所有记录，显示数量统计
- **已建档**：仅显示已关联围挡的记录
- **未建档**：仅显示尚未关联围挡的记录

#### 工具栏按钮

- **批量导入**：打开导入弹窗（支持 .xlsx/.xls/.csv，单次最多500条）
- **导出**：导出当前列表数据

#### 数据表格列

| 列名 | 宽度 | 说明 |
|------|------|------|
| 围挡编号 | 110px | WD-YYYY-NNNN格式 |
| 项目工程 | 22% | 项目名 · 工程名 |
| 地址 | 18% | |
| 行业类型 | 6% | 居中 |
| 围挡状态 | 7% | 居中，带颜色标签 + tooltip说明计算规则 |
| 围挡长度(m) | 8% | 居中 |
| 占道面积(m²) | 8% | 居中 |
| 问题状态 | 7% | 居中 |
| 计划拆除日期 | 9% | 居中 |
| 更新时间 | 9% | 居中 |
| 操作 | 18% | 居中，可换行 |

#### 操作按钮（每行）

**已建档行：**
- **详情**：跳转到围挡详情页 detail_info_v2_project.html，传递 project + engineering 参数
- **巡检记录**：跳转到围挡详情页巡查记录Tab，URL带 #sec-inspect hash
- **变更**：跳转到围挡变更页 change_v2_project.html
- **二维码**：弹出二维码弹窗
- **删除**：弹出删除确认弹窗

**未建档行：**
- **新增围挡**：触发新增流程

#### 共用围挡展示

同监管端：主行 + 子行分组，左侧蓝色竖条标识。

#### 分页器

- 显示总记录数
- 翻页按钮

#### 弹窗

1. **批量导入弹窗**：文件上传区域
2. **删除确认弹窗**：红色警告 + 围挡详情
3. **二维码弹窗**：二维码图片 + 下载按钮
4. **红线未完善提醒弹窗**：引导前往红线绘制
5. **新增方式选择弹窗**：新增围挡 / 关联现有围挡
6. **关联围挡弹窗**：搜索 + 围挡列表 + 单选确认

#### 新增围挡流程

1. 选择项目 → 点击「新增围挡」
2. 检查该项目是否已绘制红线
3. 未完善 → 弹出提醒弹窗 → 可跳转红线绘制页面
4. 已完善 → 弹出选择方式弹窗
5. 选择「新增围挡」→ 跳转到 detail_v2_project.html
6. 选择「关联现有围挡」→ 弹出关联弹窗 → 确认关联

## 四、业务规则

### 4.1 围挡状态

- 仅允许4种状态：**设置中、即将拆除、超期未拆除、已拆除**
- 状态由系统自动计算，不可手动设置

### 4.2 问题状态

- 三种状态：**正常、待整改、整改逾期**

### 4.3 红线前置校验

- 新增围挡前，必须先完善该项目工程的红线信息
- 项目端可直接绘制红线（监管端只能查看）

### 4.4 共用围挡

- 一个围挡可被多个项目工程共用
- 共用围挡在列表中以分组形式展示

### 4.5 变更操作（与监管端校核的区别）

- **项目端 → 变更**：由施工单位/建设单位发起，修改围挡信息，生成变更记录
- **监管端 → 校核**：由监管单位发起，校核修正围挡信息，生成校核记录
- 两者操作流程相同，但角色和记录类型不同

### 4.6 全景数据共享

- 使用 IndexedDB 在页面间传递全景数据（同监管端）

### 4.7 数据权限

- 项目端用户只能查看和操作自己所属项目的围挡数据
- 列表页通过项目选择器筛选，仅显示当前项目的围挡
- 无法查看其他项目的围挡信息

## 五、APP端适配建议

### 5.1 核心功能优先级

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | 围挡列表查看 | 按项目筛选、状态切换 |
| P0 | 围挡详情查看 | 7个Tab章节的移动端适配 |
| P0 | 巡检记录 | 新增巡检（手机拍照）、查看全景、问题上报 |
| P0 | 围挡变更 | 移动端变更表单 |
| P1 | 二维码扫描 | 扫码查看围挡信息 |
| P1 | 红线绘制 | 移动端地图绘制红线 |
| P2 | 数据导出 | 简化版导出功能 |

### 5.2 移动端特殊交互

- **全景照片**：利用手机陀螺仪实现方向感应浏览
- **地图绘制**：简化为点击地图添加点位，适合触屏操作
- **拍照上传**：直接调用手机相机拍摄全景/巡检照片
- **二维码扫描**：调用手机摄像头扫描围挡二维码
- **定位**：利用GPS自动填充巡检位置

### 5.3 与监管端APP的差异

| 对比项 | 监管端APP | 项目端APP |
|--------|-----------|-----------|
